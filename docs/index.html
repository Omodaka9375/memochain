Scope

01 / 05

Everything a long-horizon agent needs.

Three commitments shape the whole system: the memory never grows, the arithmetic is bit-exact across machines, and every write can be independently verified. No teacher weights appear anywhere in training.

CapabilityCovers
The memory
foldConstant size. 100 documents or 100,000 — the state is still 22,528 bytes. A portable file, not a growing index.
writeO(1) Delta rule. Each document is one integer matrix update: 0.45 ms on a laptop CPU core. No re-encoding of history.
readO(1) query-conditioned read. Question keys address the state; 16 memory tokens come back for the frozen decoder.
forgetLearned decay. Per-head beta (write strength) and decay (forgetting); rewriting a fact under the same key replaces it.
The honesty
bit-exactPure integer math. Q14 fixed point, integer square root, multiply-add-shift. Same inputs, same 256-bit digest on any machine.
receiptsReceipt chain. Every write emits a SHA-256 receipt; a light client holds three fields forever and verifies in O(1).
zk proofRecursive IVC. Mina-style: the base proof covers the whole fold, each new document is one recursive step, verify ~28 ms.
tamperTamper detection. A flipped bit in the capsule fails the hash check loudly on load — never silent corruption.
The training
e2eNo teacher anywhere. Gradients flow from a frozen LLM's own cross-entropy loss through memory tokens into the writer.
q14 steStraight-through quantization. Trained weights survive hard int16 with no accuracy cliff: 0.999991 cosine vs float.
causalZero future leakage. Every training question folds only documents strictly prior to that turn (doc_end_idx slicing).
domainsDomain transfer. Trained on a real developer's 241 coding sessions: coding recall doubles, 96.6% of the QA gain stays.
The deployment
proxyOpenAI + Anthropic APIs. Drop-in proxy on /v1/chat/completions and native /v1/messages (Claude Code, OpenRouter, direct Anthropic, vLLM, llama.cpp, Ollama).
containerSingle slim container. ~52 MB RAM, 0 extra GPU, 235 MB image, 2-second boot. Default hybrid mode pairs the 22 KB Q14 capsule with a rolling fact sheet and int8 SQLite chunk recall (capped at 2,000 chunks).
auditBackground proofs. The proxy's proof queue replays each fold in the zkVM and verifies the capsule against its SHA-256 receipt chain via /v1/memochain/verify.
tests74 Python + 14 Rust tests. Core and proxy run on any CPU; training fits a 12 GB GPU; proofs run on Linux/ARM.

Capsule

02 / 05

The entire wire format, in full.

One envelope, versioned, hash-chained. The state is the payload; the envelope is the commitment. On-disk layout:

State
22,528 B
Envelope
22,606 B
Writer weights
3.6 MB
Head count
11
Fact slots
352

Comparison: the Memorilla teacher's KV cache for the same 200-document history is 4.10 MB. The 22 KB capsule retains 98.5% of that memory gain — at 181.8× smaller.

Proof

03 / 05

What the proof proves.

"This 22 KB state was produced by running committed writer weights over the document sequence committed to this accumulator." Precisely that — and honestly, nothing more:

SurfaceCovers
provesThe fold. State, step, state digest, and accumulator are all derived from the committed weights and documents inside the zkVM guest.
recursionMina-style IVC. Base proof covers 199 documents (238.9M cycles, 1.24 MiB); each +1-doc step verifies the previous proof (33.8M cycles).
verify~28 ms anywhere. No history access, no weights, no GPU. A light client checks three fields in O(1).
freivaldsExact inner products. Batches larger than 4 documents are checked inside the guest with 2-round exact i128 Fiat–Shamir Freivalds (soundness ≤ 2⁻¹²⁸).
four-wayBit-exact agreement. Python = native Rust = zkVM execute = zkVM proof, on real unseen sessions.
does notHonest scope. Does not prove the embedding model ran honestly, does not constrain the downstream decoder, and in default hybrid proxy mode the SQLite chunk store and LLM fact sheet sit outside the ZK circuit.

Start

05 / 05

Run it in four commands.

Core + 74 tests on a laptop CPU; single-container hybrid proxy in 52 MB RAM for local models, OpenRouter, or Claude; training on a single 12 GB GPU; proofs on Linux/ARM.

Single-container memory proxy (hybrid default)

Drop-in layer in front of vLLM, llama.cpp, Ollama, OpenRouter, or Anthropic. Keeps recent 80k tokens verbatim, folds overflow into the 22 KB capsule + int8 SQLite recall + rolling fact sheet.

# Docker (recommended: 235 MB image, ~52 MB RAM, 0 extra GPU)
docker compose up -d

# Or directly via Python
uv sync --extra proxy
PYTHONPATH=src python -m memochain.server \
    --backend-base-url http://localhost:8000/v1 --port 9000
Endpoints /v1/chat/completions · /v1/messages · /v1/memochain/verify Footprint ~52 MB RAM · 0 GPU Hot window 80k / 40k tokens

Core + tests (pure numpy, any CPU)

Fold, read, verify, tamper-check, benchmark. No torch, no GPU, no downloads.

uv sync --extra dev
uv run pytest          # 74 tests (torch tests skip if absent)
uv run demo.py
Requires Python 3.12+ · numpy Runtime < 1 min

Train the 22 KB memory (no teacher)

Frozen Qwen3-0.6B provides the loss; gradients flow into the integer writer. 0.37 s/step, 6.4 GiB VRAM.

uv sync --extra train
PYTHONPATH=src python -m memochain.train_e2e \
    --decoder Qwen/Qwen3-0.6B --dataset pv4 \
    --steps 3000 --save runs/e2e_pv4
Requires 12 GB GPU · torch Runtime ~18 min Exports weights.bin · reader.npz

Zero-knowledge proof (Linux / macOS / ARM)

Prove the whole fold as a compressed recursive STARK; anyone verifies in ~28 ms.

cd crates/sp1/ivc-program && cargo prove build
cd ../script && cargo build --release --bin ivc
./target/release/ivc prove --weights weights.bin \
    --docs docs.bin --out-proof proof.bin
Base proof 199 docs · 1.24 MiB Recursive step +1 doc · 33.8M cycles Verify ~28 ms
